# Documentación de SEOStore

SEOStore es una **plantilla de sitio web orientada a ecommerce**, pensada para reutilizarla con distintos clientes. El mismo código puede operar como tienda online o como vitrina de productos, según la configuración del negocio.

## Estado resumido

Listo para usar como **backend de catálogo** y **vitrina pública** (home, productos por slug, categorías, metas, sitemap). El carrito JWT y el registro existen. Pedidos, pagos, páginas/blog públicos y checkout todavía no están cerrados.

Swagger en desarrollo: `http://localhost:5251/swagger`
